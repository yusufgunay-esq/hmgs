Drive + Google Tasks bağla

OAuth sadece HTTP üzerinde çalışır. Telefon dahil her cihazdan kullanmak için bu dosyayı GitHub Pages'e koy (ücretsiz, kurulum rehberi aşağıda).

1
PC'de test için (tek cihaz):
PowerShell'de bu klasörde çalıştır:
python -m http.server 8000
Sonra: http://localhost:8000
2
Telefon + her cihaz için: GitHub Pages
GitHub'a üye ol → yeni repo oluştur (public) → bu klasörü yükle → Settings → Pages → Branch: main → Kaydet.
URL: kullanicin.github.io/repo-adi — her cihazdan açılır.
3
Google Cloud Console → console.cloud.google.com
Yeni proje → APIs & Services → Library → Google Drive API + Tasks API ikisini de etkinleştir.
4
OAuth Client ID oluştur → Credentials → Web application.
Authorized JS origins'e sitenin URL'ini ekle:
http://localhost:8000 https://kullanicin.github.io OAuth Consent Screen → External → Test Users'a kendi mailini ekle.
5
Google Tasks Liste ID'si — Google Tasks'ta hangi listeyi kullanıyorsun? Liste adını gir, bağlandıktan sonra otomatik eşleştirelim. Boş bırakırsan varsayılan liste kullanılır.
6
Client ID'ni yapıştır ve bağlan:

Bağlantısız da çalışır. Veriler yalnızca bu tarayıcıda saklanır.
